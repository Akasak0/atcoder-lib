# atcoder-lib

競技プログラミング用の C++ ライブラリ集です。

## 内容

|名称|内容|
|-|-|
|template.cpp|実際にコンテスト参加時に使っているテンプレートです。|
|libraries|ライブラリを入れているディレクトリです。|
